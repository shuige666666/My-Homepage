## 整体

有，建议不要只逛 Dribbble，而是按“整站灵感、可运行案例、底层技术”三个层次看。下面这些站点比较值得长期收藏。

### 整站动效与视觉灵感

- [Awwwards](https://www.awwwards.com/websites/animation/)
  高质量品牌站、作品集和实验性网站很多，可以按 `Animated`、`WebGL`、`3D`、`GSAP`、`Scrolling` 等技术标签筛选。适合观察首屏、滚动叙事、页面转场和整体节奏。[Awwwards 的分类体系](https://www.awwwards.com/basic/collections/)也覆盖了 CSS Animation、WebGL、3D、GSAP、Framer 等方向。
- [Godly](https://godly.website/)
  偏当代审美，收录很多视觉冲击力强的创意网站。比 Awwwards 更适合快速刷灵感，尤其是创意工作室、科技产品和作品集网站。
- [Hoverstat.es](https://www.hoverstat.es/)
  风格更实验、更另类，经常能看到非常规排版、鼠标交互、怪异转场和 WebGL 效果。适合寻找“不像模板”的方案。
- [SiteInspire](https://www.siteinspire.com/)
  整体更克制，适合参考“动效服务于内容”的商业网站，而不只是追求炫技。

### 能看到实现思路或源码的地方

- [Codrops Creative Hub](https://tympanus.net/codrops/hub/all/codrops/)
  这是我最推荐的学习入口。大量案例附带文章、在线 Demo 和源码，并能按 `GSAP`、`Three.js`、`WebGL`、`scroll`、`page transition`、`typography` 等标签查找。目前收录了数百个实验案例，包括滚动视差、文字动效、图片扭曲、3D 场景和页面转场。[案例库](https://tympanus.net/codrops/demos/)可以直接浏览。
- [GSAP Showcase](https://gsap.com/showcase/)
  适合研究成熟商业项目中的时间轴、滚动绑定、文字拆分和复杂编排。遇到“随着滚动逐帧推进”“元素吸附、回弹、错峰进入”这类效果，通常可以从 GSAP 方向找。
- [CodePen](https://codepen.io/search/pens?q=gsap animation)
  最适合拆解单个效果。搜索时不要只输入 `animation`，可以用 `magnetic button`、`image trail`、`text reveal`、`scroll distortion`、`liquid shader`、`page transition` 等具体关键词。
- [Motion Examples](https://motion.dev/examples)
  如果使用 React，适合参考布局切换、拖拽、弹簧动画、手势交互以及 `AnimatePresence` 一类组件级动效。

### 3D、粒子和 WebGL

- [Three.js Examples](https://threejs.org/examples/)
  Three.js 官方案例库，覆盖粒子、模型动画、后处理、着色器、物理材质和 WebGPU。它更像“能力字典”：看到炫酷网站后，可以来这里确认背后究竟用了哪类图形技术。
- [React Three Fiber Examples](https://docs.pmnd.rs/react-three-fiber/getting-started/examples)
  React 项目需要 3D 时更实用，可以了解 Three.js 场景如何组件化，以及怎样和页面状态、鼠标、滚动联动。
- [Shadertoy](https://www.shadertoy.com/)
  液体、火焰、噪声、光线、扭曲、分形等 GPU 效果的宝库。不过这里偏 GLSL 图形编程，学习门槛明显更高。

### 微交互和可直接嵌入的动画

- [Rive](https://rive.app/)
  适合按钮状态、角色反馈、加载动画、数据驱动插画等真正可交互的动画。它通过状态机连接 hover、click、数值输入等状态，比单纯播放视频或 GIF 更适合产品 UI。[官方功能说明](https://rive.app/features)展示了状态机、数据绑定、骨骼动画等能力。
- [LottieFiles](https://lottiefiles.com/featured)
  适合图标、空状态、成功反馈和加载动画。社区动画可以直接预览，部分资源可以下载并修改；官方也提供了社区动画的筛选与编辑能力。[LottieFiles 文档](https://docs.lottiefiles.com/en/creator/14_plugins/community-animations)
- [Made in Webflow](https://webflow.com/made-in-webflow)
  很多案例可以直接 Clone，适合拆解滚动交互和页面结构，而不仅是看最终效果。站内可以按 `Animation`、`Interactions` 和 `Cloneable` 筛选。

## 创意和视觉效果

如果主要看“创意和视觉效果”，可以暂时不关心源码，重点逛下面几类站点。

### 首选三个

1. [Godly](https://godly.website/)
   最适合日常刷灵感。当代感很强，常见大字号排版、动态摄影、3D 产品展示、滚动叙事和实验性导航。浏览效率也比较高。
2. [Awwwards](https://www.awwwards.com/websites/animation/)
   适合系统性研究完整网站。可以重点筛选 `Animated`、`WebGL`、`3D`、`Portfolio`、`Experimental`，观察一个创意怎样贯穿首屏、内容和转场，而不只是某个孤立特效。
3. [Hoverstat.es](https://www.hoverstat.es/)
   更先锋和非主流，排版、鼠标反馈、页面结构经常不按常规出牌。想摆脱常见 SaaS 模板感，这个站很有价值。

### 更偏艺术与互动体验

- [The FWA](https://thefwa.com/)：数字艺术、互动叙事、品牌体验和实验性 Web 项目较多。
- [Codrops Creative Hub](https://tympanus.net/codrops/hub/all/codrops/)：虽然也提供源码，但它的 Demo 本身就是很好的视觉实验库，特别适合看字体、图片变形、无限画廊、粒子和 WebGL。
- [Shadertoy](https://www.shadertoy.com/)：适合寻找液体、噪声、光影、玻璃、火焰、分形等“材质型”视觉效果。
- [Three.js Examples](https://threejs.org/examples/)：偏技术展示，但对于粒子、后处理、反射、折射和 3D 场景很有启发。

### 更偏视觉素材和风格拼贴

- [Cosmos](https://www.cosmos.so/)：适合收集排版、摄影、材质、色彩和艺术指导灵感。
- [Are.na](https://www.are.na/)：很多设计师会建立主题灵感板，适合搜索 `web design`、`kinetic typography`、`digital experience`、`generative art`。
- [SAVEЕ](https://savee.it/)：图片流密度高，适合快速寻找视觉风格。
- [Behance](https://www.behance.net/search/projects?search=interactive website)：适合看完整的品牌视觉、动态设计和网站概念提案，不过要注意其中一部分只是概念稿，并未真正开发。

### 浏览时重点看什么

不要只记录“这个效果很酷”，最好拆成四个维度：

- **视觉母题**：玻璃、金属、颗粒、扫描线、拼贴、3D 塑料感。
- **运动语言**：弹性、惯性、延迟跟随、错峰出现、镜头推进。
- **空间结构**：纵深、遮挡、固定层、横向滚动、无限画布。
- **节奏设计**：什么时候安静、什么时候爆发、转场如何承接内容。

如果只保留一个日常组合，我会选择：**Godly 看趋势，Awwwards 看完整作品，Hoverstat.es 找出格创意，Cosmos 收集视觉素材**。这四个已经能覆盖大部分创意与视觉方向。
