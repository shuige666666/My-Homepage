# 信息展示页独立预览

此文件记录第一版样稿。当前实现已按反馈改为整屏模块与嵌入式光碟，见 [第二版修订说明](../preview-v2/修订说明.md)。

预览地址：<http://localhost:3000/preview>。在项目目录运行 `npm run dev` 后访问即可；当前使用原有的本地开发服务。

这版以「私人动画手记」为方向，使用纸白、灰绿和深蓝文字，依靠字号、留白、封面尺寸和上下错位建立层次。页面依次为个人序言、三个精选收藏入口、最近记录和通栏月度回忆。最近记录默认呈现一条主记录与三条侧记，其余六条可展开；完整的 77 条评分与短评在阅读弹层中查看。

## 实现边界

- 新入口为 `src/pages/preview.astro`，样式和浏览器交互分别位于 `src/styles/preview.css`、`src/scripts/preview.ts`，新增组件位于 `src/components/preview/`。
- 使用仓库中的真实 Bangumi 快照、原有图片和用户评论。日期表示收藏更新时间，未改写为实际看完日期。
- 原首页、开场画廊、光碟画廊及原时间轴组件源码均未修改。新收藏按钮通过预览适配逻辑调用原光碟入口，关闭后恢复到可见的新按钮。
- 未新增依赖、数据字段、服务端接口或发布配置。当前为本地预览。

## 实际验证

2026-11-12 执行 `npm run build` 成功，Astro 检查 24 个文件，0 errors、0 warnings、0 hints，生成原首页和 `/preview` 两个静态页面。Vite 仍提示原 Three.js 分块超过 500 kB。

浏览器检查覆盖 1440 × 900 桌面与 390 × 844 手机宽度，两者均无文档横向溢出；手机时间轴保留组件内部横向滚动。实际验证了：

- 主记录全文、前后翻页、无文字评论的评分、全部 77 条目录、目录返回、Esc 关闭和入口焦点恢复。
- 其余六条最近记录的展开与收起。
- 十月记录展开、对应评论跳转、十一月空状态，以及一年和两年范围切换。
- 光碟总入口从第一张打开、指定作品入口滑到「葬送的芙莉莲」，并正确返回入口焦点。
- 手机首屏、记录区、月度回忆和全文弹层排版；评论弹层内部没有横向溢出。

未观察到浏览器错误。打开原光碟画廊时，显卡着色器报告了浮点精度 warning，实际画廊正常显示；该画廊实现保持原样。
