# 长评（Long Reviews）模块开发记录

最后更新：2026-11-27

本文记录「长评（Long Reviews）」模块的设计参考、Bangumi 日志接口调研、独立样稿验证（`demo2/`）以及最终接入 Astro 主站的完整过程与后续定制方法。

---

## 一、设计参考与转化思路

长评模块目前收录 3 篇高浓度个人观后长评（未来以低频、少而精节奏增长），因此没有采用常规三栏卡片博客，而是融合了两类刊物型网站的设计语言：

1. **展陈与滚动节奏参考 — [Stripe Press](https://stripe.press/)（[Boom](https://stripe.press/book/boom) / [The Big Score](https://stripe.press/book/the-big-score)）**
   - 去掉复杂的 3D 立体书模型，保留其最具辨识度的版面与滚动语言：
     - **跨篇连续 RGB 色彩过渡**：滚动穿过不同长评时，背景与文字色按作品氛围平缓渐变（酒红 `#4A1F2A` → 林绿 `#1B392C` → 暮蓝 `#1B3144` → 尾声自然回归主站暖纸白 `#f8faf7`）。
     - **横屏宽幅左图 + 停驻阅读**：左侧高幅图片框在进入时纯纵向平移归中（宽恒定 100%、不缩放、保持原图比例），定住后保持完全静止，由“图片定住后的下一次滑动”推动右侧长栏（开篇节选、信息账本、制作信息与篇幅记录）向下滚动，待右侧滑到底再释放左图离场。
     - **顶部双层细线栏 + 水平滑动标题带 + `[ESC]` 全屏目录抽屉**：只在进入长评章节后滑入显现，退回「观看时间轴」或滑至页脚时自动收起，不干扰主站原有章节。
     - **完整保留 `[ ARCHIVE · 作品档案 ]` 区块**：左列虚线规格账本 + 右列 `01–0N` 缩略图切图画廊，并在关联作品含短评时呈现 Bangumi 短评引用。

2. **单篇长文阅读参考 — [PINTSCOPE](https://www.pintscope.com/)（例：[kishii-morita-sode](https://www.pintscope.com/kishii-morita-sode/)）**
   - 独立静态详情路由 `/reviews/[id]` 采用素白底色（`#ffffff`）与 17px 标准字号（`line-height: 2.05`、`letter-spacing: 0.035em`、`font-feature-settings: "palt"`）。
   - 顶部 `3px` 细线阅读进度条（随篇目主题色变化），桌面端采用非对称双栏（左粘性题头与关联条目卡片 + 右克制正文）。
   - **严格忠于原文**：不自行加小节标题、不插入摘句块，去掉大纲与标签；日志自带随文附图时在顶部全幅呈现，无附图时在左侧栏完整无裁剪展示 Bangumi 番剧海报。

## 二、Bangumi 长评接口与数据同步

Bangumi 公开 API（`api.bgm.tv/v0`）未完整覆盖用户日志，本项目采用 Bangumi Next 私有服务 `https://next.bgm.tv/p1`（规范见 [bangumi/server-private](https://github.com/bangumi/server-private)）：

| 用途 | 接口路径 |
| --- | --- |
| 用户公开日志列表（分页） | `GET /p1/users/860550/blogs?limit=20&offset=0` |
| 单篇完整标题与正文 | `GET /p1/blogs/{id}` |
| 日志关联的全部动画条目与制作信息 | `GET /p1/blogs/{id}/subjects` |
| 日志自身上传的随文附图 | `GET /p1/blogs/{id}/photos` |

### 同步与容错策略

- 同步逻辑封装在 [scripts/sync-long-reviews.mjs](file:///e:/Study/My%20Homepage/scripts/sync-long-reviews.mjs)，并接入 [scripts/sync-bangumi.mjs](file:///e:/Study/My%20Homepage/scripts/sync-bangumi.mjs)（随 GitHub Actions 每日定时运行）；也支持单独执行 `npm run sync:long-reviews` 仅刷新长评数据。
- **私有接口兜底**：若 `next.bgm.tv/p1` 临时波动，脚本会保留上次快照中的 `longReviews`，不会阻断主站日常收藏、评分与时间轴同步。本机 Windows TUN 环境下若原生 `fetch` 出现 socket 断开，脚本会自动回落至系统 `curl`。
- **自动配图规则**：优先使用日志自身上传的随文附图（转为 WebP 存入 `public/images/bangumi/`）；没有附图时自动复用或下载关联番剧的 Bangumi 官方海报。

## 三、与原主流程的衔接方案与动效设计

长评模块直接拼接在主站原有流程的最尾部：

`开幕画廊` → `个人序言` → `我最喜欢的动漫` → `最近看过` → `评分与短评` → `观看时间轴` → **`长评（Long Reviews）`** → `页脚`

1. **「观看时间轴 → 长评」暗场沉降过渡**：
   - 在 [PreviewLongReviews.astro](file:///e:/Study/My%20Homepage/src/components/preview/PreviewLongReviews.astro) 顶部设置 `.pv-lr-curtain` 过渡幕，并与 [preview-snap.ts](file:///e:/Study/My%20Homepage/src/scripts/preview-snap.ts) 统一接管滚动状态机。
   - 在「观看时间轴」向下滚动时，触发约 `1020ms` 对称缓入缓出（`morphEase`）滑过过渡幕：背景从时间轴浅灰绿 `#eaf0eb` 连续沉降为第一篇的深酒红 `#4A1F2A`，居中浮现 `LONG REVIEWS · 长评` 过渡字标并随上滑隐退，顶部细线栏与水平标题带从顶边轻柔滑入，第一篇大图升起并精准定格在 `lockY`。
   - 到达首篇 `lockY` 后若向上滚动，则对称逆向退回「观看时间轴」并自动收起长评顶栏。
2. **篇目定住停顿与双向联动**：
   - 后续每篇长评的 `lockY` 均作为 `preview-snap.ts` 的边界点：向下跨过时先精准定住左图并吞掉余滑，下一次滑动再推动右侧内容滚动。
   - 顶部导航栏新增「长评」锚点；「评分与短评」（[PreviewShowcase.astro](file:///e:/Study/My%20Homepage/src/components/preview/PreviewShowcase.astro)）中凡是写过长评的作品，右侧自动出现 `阅读长评 ↗` 直达入口。
3. **尾声回归主站页脚**：
   - 滑至末篇下方尾声带（显示「永远相信美好的事情即将发生」）时，背景平滑亮回主站纸白 `#f8faf7`，顶部细线栏自动收起，自然衔接底部 `.pv-footer-band`。

## 四、后续可选轻度定制指南（替换 `[ ARCHIVE ]` 配图 / 主题色）

配置文件位于 [src/data/long-reviews.config.json](file:///e:/Study/My%20Homepage/src/data/long-reviews.config.json)，默认为空对象 `{ "overrides": {} }`（全自动模式）。

后续找到想放在 `[ ARCHIVE ]` 档案区右侧的剧照或插图后：

1. 将图片放入 `public/images/long-reviews/`（目录可自行新建）。
2. 在 `src/data/long-reviews.config.json` 中按日志 ID（如 `383072`、`343330`、`335943`）填写对应字段：

```json
{
  "overrides": {
    "383072": {
      "archiveImages": [
        { "src": "/images/long-reviews/azumanga-still-1.webp", "caption": "毕业式教室" },
        { "src": "/images/long-reviews/azumanga-still-2.webp", "caption": "春日合影" }
      ],
      "theme": {
        "bg": "74, 31, 42",
        "fg": "244, 206, 216",
        "accent": "#B83644"
      }
    }
  }
}
```

- `heroImage`（可选）：单独覆写上方左图的视觉图路径；不写则继续自动用 Bangumi 附图或番剧海报。
- `archiveImages`（可选）：单独覆写 `[ ARCHIVE ]` 档案区右侧的图库列表（支持 1–5 张，会自动测量宽高并决定裁切方式）；不写则继续使用 Bangumi 自动收集的图片。
- `theme`（可选）：覆写该篇的展陈背景色（RGB）、前景色（RGB）与阅读页进度条强调色（HEX）。
3. 修改配置后运行 `npm run sync:long-reviews` 和 `npm run build` 即可生效。
